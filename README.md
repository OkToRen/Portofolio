# Darren Oliver P. Haryanto - Portfolio

A modern, interactive portfolio website showcasing my professional experience, education, and skills as a Computer Science student and Lab Resource Management Officer at Bina Nusantara.

## 🚀 Tech Stack

- **[Astro](https://astro.build)** - Fast, modern static site framework
- **[Tailwind CSS](https://tailwindcss.com)** - Utility-first CSS framework (v4.1.18)
- **[Lenis](https://lenis.darkroom.engineering)** - Smooth scrolling
- **TypeScript** - Type-safe JavaScript

## ✨ Features

- Modern, responsive design
- Smooth animations and transitions
- Showcase of professional experience
- Education and skills display
- Contact information

## 🛠️ Installation

1. Clone the repository:
```sh
git clone <your-repo-url>
cd portofolio
```

2. Install dependencies:
```sh
npm install
```

3. Start the development server:
```sh
npm run dev
```

The site will be available at `http://localhost:4321`

## 📜 Available Commands

| Command              | Action                                      |
| :------------------- | :------------------------------------------ |
| `npm install`        | Install dependencies                        |
| `npm run dev`        | Start local dev server at `localhost:4321`  |
| `npm run build`      | Build production site to `./dist/`          |
| `npm run preview`    | Preview your build locally before deploying |
| `npm run astro ...`  | Run CLI commands like `astro add`           |
